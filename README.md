# kyulee-jeon.github.io

Personal academic website of Kyulee Jeon. Static HTML with a dark theme (`assets/main.css`).

## Publish

1. Create a public repository named `kyulee-jeon.github.io`.
2. Put these files in the repository root and push to `main`.
3. In the repository: Settings > Pages > Source: `main` branch, `/ (root)`.
4. The site is served at https://kyulee-jeon.github.io

## Update

- Photo: add `images/KyuleeJeon.jpg` (square). `index.html` already points to it; the initials image is shown until the file exists.
- CV: replace `data/KyuleeJeon-CV.pdf`.
- Publications: copy one `<article class="pub">` block in `index.html` and edit it.
